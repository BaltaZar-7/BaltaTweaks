# BaltaTweaks
Small tweaks made by me.  
## List
- No auto closing doors - disable auto closing doors (Blackrock and TFT)  
- Persistent Books - Unstack books, so they do not lose their identity. They do not convert all into BookA anymore. Good for book collecters.
- Shows used Tip up condition on the Tip up panel when ice fishing. Useful because you basically want to harvest the tip up, before breaking.
- Toolbelt: fixes the missing affect for survival and cougar knives. Can change the number of items affected by the belt. If you have Clothing Expanded mod installed, then you these change will only matter if you have the belt equiped as an accessory item. The cougar, survival knives inject works the same, only if the belt is equiped as accessory.  
# Installation
Download and install dependancy mod: ModSettings  
Download and place the dll file into your \Mods folder.
