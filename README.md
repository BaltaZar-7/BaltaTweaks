# BaltaTweaks
Small tweaks made by me.  
## List
- No auto closing doors - disable auto closing doors (Blackrock and TFT)  
- Persistent Books - Unstack books, so they do not lose their identity. They do not convert all into BookA anymore. Good for book collecters.
# Installation
Download and install dependancy mod: ModSettings  
Download and place the dll file into your \Mods folder.
